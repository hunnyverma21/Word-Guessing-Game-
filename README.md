# Word Guessing Game

A responsive, Wordle-inspired browser game built with HTML, CSS, and JavaScript.

## How to play
1. Enter a valid 5-letter word from the game's built-in word list.
2. You have 6 attempts to discover the hidden word.
3. **Green** means the letter is correct and in the correct position.
4. **Yellow** means the letter is in the word but in a different position.
5. **Gray** means the letter is not in the hidden word.
6. Use **Get a hint** for a letter hint, or **New game** to restart.

## Run locally
Download or clone this project, then open `index.html` in your browser. No installation is required.

## Deploy on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Select your `main` branch and `/ (root)`, then save.

## Features
- Responsive design for desktop and mobile
- Six attempts per round
- Duplicate-letter-aware color feedback
- Hint button
- Win counter saved in browser local storage
- No frameworks or external APIs required
